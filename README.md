Project Overview
This project involves designing and developing a professional, fully functional website for GreenRoots NPO, a non-profit organisation based in Johannesburg, South Africa. GreenRoots NPO is dedicated to transforming underutilised urban land into thriving community gardens, promoting environmental education, food security, and community empowerment across Gauteng.
The project is completed in three parts:
Part 1 (Complete): Project planning, HTML structure, content research, and GitHub repository setup.
Part 2 (Complete): CSS styling, responsive design, and user experience improvements.
Part 3 (Upcoming): JavaScript functionality, form validation, animations, and SEO optimisation.
---
Website Goals and Objectives
Primary Goals
Establish a strong online presence for GreenRoots NPO to increase community awareness and engagement.
Provide clear, accessible information about the organisation's programmes and impact.
Enable easy volunteer and sponsor sign-ups through an online enquiry form.
Showcase garden locations and make them easily findable via embedded maps.
Key Performance Indicators (KPIs)
Increase volunteer enquiries by 40% within 6 months of launch.
Achieve a Google PageSpeed score of 85+ on mobile.
Attract at least 3 new corporate partnerships within 12 months.
Reduce bounce rate below 50% through clear navigation and engaging content.
